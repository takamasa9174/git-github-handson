# git-github-handson

## Git / GitHub ハンズオン

Git / GitHub の基本操作を学ぶためのハンズオン教材リポジトリです。IBM i開発者向けの勉強会（Gitと GitHubの基礎）で使用しています。

### このリポジトリについて

- 収録しているソースはすべて**架空の得意先管理システム**のダミープログラムです（IBM i・固定長RPGIVで作成）
- 実在のシステム・企業データとは一切関係ありません
- 演習を通じて、Gitの「コミット」「ブランチ」「マージ」の基本的な考え方を体験することが目的です

### 前提環境

- IDE：VS Code または IBM Bob（内部はVS Codeベース）のいずれか
- Git：[Git for Windows](https://git-scm.com/) 導入済みであること
- ネットワークに接続できる端末（拡張機能のインストール等を行うため）
- **IBM i への接続は不要です**。演習はすべてローカル環境で完結します
- AIエージェント連携（Bob・Claude Code等）は今回の演習の対象外です

### 構成

架空の得意先管理システムを構成する、以下のダミーソースを収録しています。

| 種別 | ソース名 | 内容 |
|------|----------|------|
| RPGプログラム | `BCH01R` | 得意先一覧表（バッチ） |
| RPGプログラム | `INT01R` | 得意先マスター照会 |
| RPGプログラム | `INT02R` | 受注エントリー（サブファイル） |
| RPGプログラム | `INT03R` | 得意先マスター照会（自由形式RPGへの変換演習用） |
| 物理ファイル | `TECSMP` | 得意先マスターファイル |
| 物理ファイル | `TEITMP` | 品目マスターファイル |
| 物理ファイル | `TEJUTP` | 受注ファイル |
| 表示装置ファイル | `INT01RD` | 得意先マスター照会 画面 |
| 表示装置ファイル | `INT02RD` | 受注エントリー 画面 |
| 表示装置ファイル | `INT03RD` | 得意先マスター照会（変換演習用） 画面 |

### 演習の進め方

| # | 操作 | ブランチ | 対象ファイル | 内容 |
|---|------|---------|------------|------|
| 1 | clone | - | - | VS Code / IBM Bobの「Clone Repository」機能でこのリポジトリをローカルに取得する |
| 2 | 編集→ステージ→コミット | `main`のまま | `INT01RD` | 画面タイトル文言を少し直し、変更をステージング→コミットする |
| 3 | ブランチ作成〜作業〜コミット | `feature/add-district-code`（新規作成） | `INT01RD`・`INT01R` | 「地区コード」の表示を追加する変更を行い、コミットする |
| 4 | mainに戻る→マージ | `main` | - | 3で作った`feature/add-district-code`ブランチをマージする |
| 5 | 過去のコミットを見る | - | - | Git Graph等で、これまでのコミット履歴を確認する |

（時間に余裕がある方向け）

| # | 操作 | ブランチ | 対象ファイル | 内容 |
|---|------|---------|------------|------|
| 6 | ブランチ作成〜変換 | `feature/convert-int03r-ffrpg`（新規作成） | `INT03R` | 自由形式RPGに変換する（コミットはしない）。他のブランチ（模範解答）と見比べてみるのもおすすめです |

### ライセンス・利用について

本リポジトリは教材用の学習リポジトリです。内容の二次利用は演習目的に限り自由です。実際の業務プログラムへのコピー・流用は禁止します。
